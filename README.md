## Selected projects

### [Invoice Operations Automation](https://github.com/avivgur/invoice-operations-automation)

A safe, auditable invoice reconciliation pipeline designed around real finance-operations risks.

- Deterministic reconciliation with add, update, archive, review, and unchanged outcomes
- Human-review routing for suspicious financial changes
- Google Sheets integration, synthetic demo data, and dry-run-first execution
- Typed Python architecture with automated linting, type checking, and tests

**Focus:** Python · Pydantic · Google Sheets · Data Pipelines · GitHub Actions

### [Piano Tracker](https://github.com/avivgur/piano-tracker)

An end-to-end system for capturing piano practice sessions from a MIDI-enabled instrument and turning them into useful learning data.

- Raspberry Pi hardware integration and MIDI event capture
- FastAPI backend with PostgreSQL
- Web application for viewing and managing practice activity
- Architecture spanning edge hardware, cloud services, and user experience

**Focus:** Python · TypeScript · FastAPI · PostgreSQL · Raspberry Pi · MIDI
